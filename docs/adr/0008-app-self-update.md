# ADR-0008：应用更新交给 MyGo 的更新插件

状态：已接受

## 上下文

在此之前，「关于」页里有一段自己写的更新检查：拉 GitHub 最新 release 的标签，用 `app.ToolNewer` 逐段比较数字，然后给一个下载页链接。用户要自己离开应用、下载安装包、关掉应用、手动运行安装包；除了走到「关于」按一下，没有任何东西告诉用户有新版。

MyGo 自带签名更新（`mygo.Updater`）与一个更新窗口插件：后者按 Sparkle 的流程检查、显示更新说明、下载、安装并重启，其中 `plugins/updater/native` 用原生控件画窗口，不需要 WebView。应用没有 WebView，Windows 10 上也不应该为此多装 WebView2 Runtime。

## 决定

1. **用原生控件版的插件**：`mygo.Use(native.New(updater.Options{...}))`，在读取配置之后、`App.Run` 之前注册一次。不用网页版，理由是没有 WebView 的依赖链。
2. **语言在启动时选一次**：跟随系统时传系统的首选语言标签，简体中文传 `zh-Hans`，英文传 `en`。不传空值——空值让插件去读 `App.Locale`，而本应用没有注册 MyGo 的语言目录，读到的是英文。代价是运行中切换界面语言后，更新窗口与托盘条目要到下次启动才换语言；不为此把语言选择再存一份到工具目录之外。
3. **检查节奏与偏好归插件**：启动后不久检查一次，此后每天一次；间隔、上次检查时间、跳过的版本、两个开关都写在用户数据目录的 `updater.json` 里，配置文件不加字段。应用的窗口状态本来就写在那个目录，这不算新起一份。
4. **自动检查默认关闭**：插件自己的默认是开启的，本应用用 `DisableAutomaticChecks: true` 改成关闭。自动更新本质上是信任问题，不替用户做「相信本项目的发布」这个决定；用户打开「设置 → 通用」的开关之后，插件记住的是用户的选择。
5. **应用只保留三处界面**：托盘菜单插入插件自己的「检查更新…」条目（在「打开 Lua 目录」之后、「退出」之前）；「关于」的「应用更新」行只调插件的手动检查，且不禁用（插件没有忙碌状态可读，重复点击只是把窗口提到前面），下一行在已知新版本时写出该版本；「打开下载页」保留给不能自我更新的副本。「设置 → 通用」加一张卡，两个开关直接读写插件偏好。
6. **删掉自己写的那套**：`app.ToolNewer` 与 `ToolCheck` 派生、`ToolChecked`/`ToolFailed`/`ToolOnline` 三项事实、只服务于它的 `BusyCheckTool` 忙碌值、只给它用的文案与测试一并删除。运行版本仍是一项事实，来自 `mygo.App.Version()`。「是 / 否有更新」从此只有一个答案：插件给的那个。
7. **签名从 0.5.0 开始**：公钥写进 `mygo.json` 的 `updates.publicKey`，随每个副本编译进去；私钥不进仓库，放在仓库密钥 `MYGO_UPDATER_PRIVATE_KEY` 里。发布流水线用 `go tool mygo build -upload` 一步完成签名与上传：安装包、更新归档、增量更新与清单一起进草稿 release，流水线再核对标签与 `mygo.json` 的 `version` 一致、清单与归档都在，才发布。清单最后上传，所以已装副本永远看不到指向缺失文件的清单。
8. **发布说明只写一次**：`CHANGELOG.md` 里 `## [<版本>]` 段落同时是更新窗口的说明与 GitHub release 正文，正文不再由 `--generate-notes` 生成。

## 后果

- 公钥从 0.5.0 起固化在每个副本里，只有用配对的私钥签出的更新才装得上。私钥丢失等于让这些副本永远停在旧版本：它们没有别的更新通道。这是本决策里唯一不可逆的部分，因此私钥必须存在仓库密钥之外的地方，另有一份离线备份。
- 0.5.0 之前的版本没有清单，也就不会检查、不会更新；第一批用户需要手动装一次 0.5.0。
- 更新只换应用自己带的文件，按版本记下的文件清单删除旧文件；用户放在可执行文件旁边的缓存（`patches/`、`cache/`、`userdata/`、`config.json`）不在清单里，更新后照旧可用。
- 更新写着「下次启动生效」时，用户关掉应用再打开即可；选「立即重启」由插件重启到新版本，不需要应用自己再起一个进程。
- `-upload` 的端到端行为（签名、增量更新、清单、草稿 release）要到第一次真发布才算验证过，本地只能验证构建与测试。
- 词表把「更新动作」改名为「补丁更新」，并新增「应用更新」，避免两件事共用一个词。
- ADR-0002 仍然成立：新增的只有从插件抄来的三项事实（可用版本、两个偏好），不落盘、不加优先级阶梯。

## 备选与排除

- 继续自己写的检查，只把下载页换成安装包直链。排除：等于自己实现下载、校验、替换可执行文件、重启，而这正是 MyGo 更新器已经做完的部分，且签名校验很难自己写对。
- 用插件的网页版窗口。排除：应用整体是原生控件，网页版在 Windows 10 上要 WebView2 Runtime，Linux 上要 WebKitGTK。
- 把两个开关写进 `config.json` 再同步给插件。排除：插件已经在写 `updater.json`，应用再存一份就有两个来源，改一处忘另一处就会不一致。
- 自动检查默认开启（插件默认值）。排除：见决定 4。
- 让插件去读 MyGo 的语言目录（`App.SetLocale`）。排除：那是把界面语言再存到工具目录之外的一处，与「配置只在工具目录里」相冲突。
