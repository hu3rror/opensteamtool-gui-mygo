# ADR-0006：补丁源以仓库地址命名

状态：已接受

## 上下文

补丁源需要在两处被用户看见：首次运行向导的「Steam 路径」步骤与设置「补丁源」页。旧界面把三件事写在同一行文字里：角色、布局、备注。

- 内置源的行文案是「官方源（长期未更新）」「社区维护」「社区维护（SteamDaddy 布局）」。括号里的备注与布局混进了名称，界面不告诉用户这些发布来自哪个仓库。
- 布局另起一行「文件布局 / OpenSteamTool 布局」。布局由源锁定（ADR-0004），不是可选项，单独成行只是重复。
- 角色、布局、备注三者最多的一个源在 320 宽的最小窗口里接近换行。

## 决定

1. 内置源的行文案改成仓库地址，取自内置源清单（`OpenSteam001/OpenSteamTool`、`huanyuejue/OpenSteamTool`、`Contrary-v2/SteamDaddy-Dll`），不另写文案。
2. 角色、布局、备注收进该行的悬浮提示，按 `角色 · 布局 · 备注` 拼接，缺哪段省略：官方源为「官方源 · OpenSteamTool 布局 · 长期未更新」，社区维护源为「社区维护 · OpenSteamTool 布局」，SteamDaddy 源为「社区维护 · SteamDaddy 布局」。
3. 悬浮提示由源键与布局推导，不逐行手写；自定义源没有固定事实，不加提示。
4. 取消「文件布局」行，向导与设置都只保留源选项。
5. 官方源长期未更新这一条会改变选择，不能只藏在悬浮提示里：草稿选中官方源时，选项下方显示一行提醒。
6. 词表把融合词「社区维护（SteamDaddy 布局）」拆成源与布局两条；源的行文案即仓库地址，布局仍是源锁定的属性。

## 后果

- 界面用用户可核对的事实（仓库地址）标识源，角色与布局退为辅助信息；悬浮提示同时作为无障碍描述，键盘聚焦也能读到。
- 三个内置源的仓库地址必须与内置源清单一致，改了清单界面自动跟随。
- 窗口宽 480 及以上时三个地址单行显示（实测 175–198 个逻辑像素）；320 宽的最小窗口里每个地址折成两行，文字不截断。
- 官方源的陈旧提醒在选中时才出现，未选中时不占空间。

## 备选与排除

- 行文案写成「角色 · 仓库」。排除：仓库地址在 480 宽时已用掉 168–198 像素，加上角色会折行，比只写地址多占一行。
- 只写角色，仓库留在提示里。排除：仓库是源之间唯一稳定的区别，藏起来等于没标识。
- 官方源的提醒只放悬浮提示。排除：只在悬停时可见的否决信息，在键盘操作与触屏上等于不存在。
- 每个源两行卡片（`ui.RadioBase` 加自定义排版）。排除：能用现成单选组件说清的信息，不值得手写排版与焦点。
